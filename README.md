# AINA Web — local ViTuTi presentation

The application, installer and required assets are in **[aina-web](aina-web/)**.

1. [Download the repository ZIP](https://github.com/lqmnwido/aina-3d/archive/refs/heads/main.zip) and extract it.
2. Open the **aina-web** folder.
3. Double-click **SETUP.cmd** and wait for setup to finish.
4. Double-click **START.cmd** to open **http://localhost:5173**.
5. Click **Start bersama AINA**. After the greeting, press **Space** or tap the screen to launch.

Read the **[step-by-step installation guide](aina-web/README.md)** for details.

Only the web app, installer, current model, four prerecorded voice clips, current montage and animation code are included in the current version. No AI, domain, Python or Blender installation is needed. Internet is required during initial setup; presentation playback then works offline.

The current montage uses Git LFS because it is over 100 MB. SETUP.cmd can download the real video if a ZIP contains an LFS pointer.
